SECTION 4: Handwritten Coding (3 × 40 total = 40 points)

25. Strategy Pattern: Payment Processor (15 points)

Implement `PaymentStrategy` (abstract), `CreditCardPayment`, `PayPalPayment`, `CryptoPayment`. Implement `ShoppingCart` with `add_item(price)`, `calculate_total()`, and `checkout(strategy)`.

Yechim:
from abc import ABC, abstractmethod

class PaymentStrategy(ABC):
    @abstractmethod
    def pay(self, amount: float) -> str:
        pass

class CreditCardPayment(PaymentStrategy):
    def __init__(self, card_number, name):
        self.card_number = card_number
        self.name = name
    def pay(self, amount):
        return f"Paid ${amount} via Credit Card ending in {self.card_number[-4:]}"

class PayPalPayment(PaymentStrategy):
    def __init__(self, email):
        self.email = email
    def pay(self, amount):
        return f"Paid ${amount} via PayPal ({self.email})"

class CryptoPayment(PaymentStrategy):
    def __init__(self, wallet):
        self.wallet = wallet
    def pay(self, amount):
        return f"Paid ${amount} via Crypto wallet {self.wallet}"

class ShoppingCart:
    def __init__(self):
        self.items = []
        self.strategy = None
    def add_item(self, price: float):
        self.items.append(price)
    def total(self):
        return sum(self.items)
    def set_strategy(self, strategy: PaymentStrategy):
        self.strategy = strategy
    def checkout(self):
        print(self.strategy.pay(self.total()))

26. Custom Context Manager: Timer (12 points)

Implement a timer using a Class (`__enter__`, `__exit__`) and a Generator (`@contextmanager`). Both must measure elapsed time and print it cleanly even if an exception occurs.

Yechim:
import time
from contextlib import contextmanager

class ClassTimer:
    def __enter__(self):
        self.start = time.time()
        return self
    def __exit__(self, exc_type, exc_val, exc_tb):
        print(f"Elapsed: {time.time() - self.start:.2f} seconds")

@contextmanager
def func_timer():
    start = time.time()
    try:
        yield
    finally:
        print(f"Elapsed: {time.time() - start:.2f} seconds")

# Usage:
# with ClassTimer(): time.sleep(0.5)
# with func_timer(): time.sleep(0.5)

27. Observer Pattern: Weather Station (13 points)

Implement `Subject` (WeatherStation tracking temperature and humidity) and `Observer` (e.g., PhoneDisplay). WeatherStation must have `attach`, `detach`, and `notify` methods.

Yechim:
class Subject:
    def __init__(self):
        self._observers = []
    def attach(self, observer):
        self._observers.append(observer)
    def detach(self, observer):
        self._observers.remove(observer)
    def notify(self):
        for obs in self._observers:
            obs.update(self)

class WeatherStation(Subject):
    def __init__(self):
        super().__init__()
        self.temp = 0
        self.humidity = 0
    def set_measurements(self, temp, humidity):
        self.temp = temp
        self.humidity = humidity
        self.notify()

class PhoneDisplay:
    def update(self, subject):
        print(f"Phone Display: Temp {subject.temp}°C, Humidity {subject.humidity}%")
