Question 1 (13 points) – Observer Pattern: Weather Station

Scenario: A weather station collects temperature data. Multiple display units (Observers) need to be notified whenever the temperature changes.

Requirements:

  • 1. Create an abstract class Observer using ABC and @abstractmethod.
    • Define an abstract method update(self, temperature).
  • 2. Create a WeatherStation class (the Subject).
    • Maintain a private list of observers (_observers).
    • Provide these methods:
      • attach(self, observer) – appends an observer to the list.
      • detach(self, observer) – removes an observer from the list.
      • notify_observers(self) – iterates through all observers and calls observer.update(self._temperature).
      • set_temperature(self, temp) – updates self._temperature and calls notify_observers().
  • 3. Create two concrete observer classes:
    • PhoneDisplay – update(self, temperature) prints: "Phone Display: Temperature is {temperature}°C".
    • WindowDisplay – update(self, temperature) prints: "Window Display: Temperature is {temperature}°C".
  • 4. Demonstration (inside if __name__ == "__main__":):
    • Create a WeatherStation.
    • Create one PhoneDisplay and one WindowDisplay.
    • Attach both observers.
    • Set temperature to 25 (both displays update).
    • Set temperature to 30 (both displays update again).
    • Detach the PhoneDisplay.
    • Set temperature to 20 (only WindowDisplay updates).
Yechim:
from abc import ABC, abstractmethod

class Observer(ABC):
    @abstractmethod
    def update(self, temperature):
        pass

class WeatherStation:
    def __init__(self):
        self._observers = []
        self._temperature = 0

    def attach(self, observer):
        self._observers.append(observer)

    def detach(self, observer):
        self._observers.remove(observer)

    def notify_observers(self):
        for observer in self._observers:
            observer.update(self._temperature)

    def set_temperature(self, temp):
        self._temperature = temp
        self.notify_observers()

class PhoneDisplay(Observer):
    def update(self, temperature):
        print(f"Phone Display: Temperature is {temperature}°C")

class WindowDisplay(Observer):
    def update(self, temperature):
        print(f"Window Display: Temperature is {temperature}°C")

if __name__ == "__main__":
    station = WeatherStation()
    phone = PhoneDisplay()
    window = WindowDisplay()
    
    station.attach(phone)
    station.attach(window)
    
    station.set_temperature(25)
    station.set_temperature(30)
    
    station.detach(phone)
    station.set_temperature(20)

Question 2 (13 points) – Strategy Pattern: Payment System

Scenario: An online store offers multiple payment methods. The customer chooses a payment strategy at checkout.

Requirements:

  • 1. Create an abstract class PaymentStrategy with an abstract method pay(self, amount).
  • 2. Create three concrete strategy classes:
    • CreditCardPayment – pay(self, amount) prints: "Paid ${amount} using Credit Card".
    • PayPalPayment – pay(self, amount) prints: "Paid ${amount} using PayPal".
    • BitcoinPayment – pay(self, amount) prints: "Paid ${amount} using Bitcoin".
  • 3. Create a ShoppingCart class:
    • Maintains a list of items. Each item is a tuple: (name, price).
    • Methods:
      • add_item(self, name, price) – appends the item.
      • calculate_total(self) – returns the sum of all item prices.
      • checkout(self, payment_strategy) – accepts a PaymentStrategy object, calls payment_strategy.pay(total), then prints "Order completed.".
  • 4. Demonstration (inside if __name__ == "__main__":):
    • Create a ShoppingCart.
    • Add three items: ("Laptop", 1200), ("Mouse", 25), ("Keyboard", 80).
    • Calculate and display the total.
    • Checkout using CreditCardPayment.
    • Create a new cart or clear it, then checkout again using PayPalPayment (you may reuse the same cart with different items).
Yechim:
from abc import ABC, abstractmethod

class PaymentStrategy(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

class CreditCardPayment(PaymentStrategy):
    def pay(self, amount):
        print(f"Paid ${amount} using Credit Card")

class PayPalPayment(PaymentStrategy):
    def pay(self, amount):
        print(f"Paid ${amount} using PayPal")

class BitcoinPayment(PaymentStrategy):
    def pay(self, amount):
        print(f"Paid ${amount} using Bitcoin")

class ShoppingCart:
    def __init__(self):
        self.items = []

    def add_item(self, name, price):
        self.items.append((name, price))

    def calculate_total(self):
        return sum(price for name, price in self.items)

    def checkout(self, payment_strategy):
        total = self.calculate_total()
        payment_strategy.pay(total)
        print("Order completed.")

if __name__ == "__main__":
    cart = ShoppingCart()
    cart.add_item("Laptop", 1200)
    cart.add_item("Mouse", 25)
    cart.add_item("Keyboard", 80)
    
    print(f"Total: {cart.calculate_total()}")
    cart.checkout(CreditCardPayment())
    
    cart2 = ShoppingCart()
    cart2.add_item("Monitor", 300)
    cart2.checkout(PayPalPayment())

Question 3 (14 points) – Factory Pattern: Document Processor

Scenario: A document processing system needs to create different types of documents (PDF, Word, Text) without exposing the creation logic to the client code.

Requirements:

  • 1. Create an abstract class Document with an abstract method open(self). Each subclass overrides open() to print a message specific to its type.
  • 2. Create three concrete document classes: PDFDocument, WordDocument, TextDocument, each implementing open() with their own message (e.g., "Opening PDF document...").
  • 3. Create a DocumentFactory class with a static method create_document(doc_type) that:
    • Takes a string: "pdf", "word", or "text".
    • Returns an instance of the corresponding concrete class.
    • Raises a ValueError for unsupported types.
  • 4. In your demonstration:
    • Use the factory to create one document of each type.
    • Call open() on each.
    • Attempt to create an unsupported type (e.g., "excel") and handle the exception properly, printing "Error: Unsupported document type".
Yechim:
from abc import ABC, abstractmethod

class Document(ABC):
    @abstractmethod
    def open(self):
        pass

class PDFDocument(Document):
    def open(self):
        print("Opening PDF document...")

class WordDocument(Document):
    def open(self):
        print("Opening Word document...")

class TextDocument(Document):
    def open(self):
        print("Opening Text document...")

class DocumentFactory:
    @staticmethod
    def create_document(doc_type):
        dt = doc_type.lower()
        if dt == "pdf":
            return PDFDocument()
        elif dt == "word":
            return WordDocument()
        elif dt == "text":
            return TextDocument()
        else:
            raise ValueError("Unsupported document type")

if __name__ == "__main__":
    for dt in ["pdf", "word", "text"]:
        doc = DocumentFactory.create_document(dt)
        doc.open()
        
    try:
        err_doc = DocumentFactory.create_document("excel")
    except ValueError:
        print("Error: Unsupported document type")
